# Baryan

**Every Peso Has a Place.**

A simple, beginner-friendly personal expense tracker focused on Philippine Peso (₱). Built with HTML, CSS, and JavaScript, Baryan helps users record income and expenses, monitor their balance, and organize transactions in one place.

## Features

- Add income and expense transactions
- Edit and delete existing transactions
- View total income, expenses, and current balance
- Search transactions by description
- Filter transactions by type and category
- Sort transactions by date
- Reset filters and sorting to their default values
- Form validation to prevent invalid entries
- Responsive layout for different screen sizes

## Built With

- HTML
- CSS
- JavaScript

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/ChildEmperor-max/personal-expense-tracker.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
